# PoViShield

**Intelligent Linux Application Sandboxing, Seccomp-BPF Policy Generation & Multi-Device Fleet Security**

PoViShield learns an application's observed system-call behavior via dynamic tracing (`ptrace`), generates empirical least-privilege seccomp-bpf policies, explains security decisions with auditable risk metrics, minimizes permissions via leave-one-out counterfactual ablation, enforces execution boundaries under the Linux kernel, and monitors multi-device Linux fleets from an enterprise cybersecurity console.

```
Terminal Command / Web Task → Pre-Execution Policy Evaluation → Security Explanation →
Safety Gate Approval Check → Kernel-Enforced Execution (Seccomp-BPF / Ptrace) →
Live Telemetry & Auditable Event Timeline → Central Fleet Synchronization
```

> **Research Prototype & Fleet Platform:** PoViShield is an advanced Linux security research prototype and fleet defense platform.
> Read [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md) and [`SECURITY.md`](SECURITY.md) for documented security boundaries and limitations.

## 3. Real Terminal CLI Supervisor (`./povishield` / `./pv`)

PoViShield provides an explicit CLI supervisor (`./povishield`, symlinked as `./pv`) that evaluates, confines, and audits execution directly from your Linux terminal:

```bash
# Permitted execution under verified least-privilege policy (Exit code 0):
./povishield run -- /usr/bin/echo "Hello from PoViShield"

# Pre-evaluate security boundaries and risk reduction before process launch:
./povishield evaluate -- /usr/bin/cat /dev/null

# Enforced Seccomp Kill Demo: unlearned syscall triggers kernel SIGSYS kill (Exit code 159 / -31):
./povishield run --profile results/profiles/echo.json -- /usr/bin/uname -a

# Safety Gate Fail-Closed Demo: unapproved commands fail closed before launch (Exit code 126):
./povishield run --mode approval-required -- /usr/bin/cat /dev/null

# Safety Gate Approved Demo: approved target executes under confinement (Exit code 0):
./povishield run --mode approval-required -- /usr/bin/grep "root" /etc/passwd

# Dynamic Ptrace Audit Mode: inspects and records live events without killing:
./povishield run --mode inspect -- /usr/bin/ls /tmp

# List recorded audit execution sessions:
./povishield list
```

### Execution Modes

| Mode | Pre-Execution Check | Enforcement Mechanism | Behavior on Unlearned Syscall |
|---|---|---|---|
| `enforce` *(default)* | Calculates attack surface reduction, risk scores, withheld critical syscalls | Linux Seccomp-BPF (`SCMP_ACT_KILL_PROCESS`, `PR_SET_NO_NEW_PRIVS`) | **Kernel Kill (`SIGSYS` / 159 / -31)** |
| `inspect` | Observes and records all syscalls via dynamic tracer | Linux Ptrace (`PTRACE_SYSCALL`) | **Audited and recorded** (Non-killing) |
| `approval-required` | Verifies candidate policy approval in `results/approvals.jsonl` | Linux Seccomp-BPF | **Fails closed (`exit 126`)** if unapproved |

## 4. Web Security Operations Console (UI & API)

PoViShield features an enterprise dark cybersecurity interface built with React 19, Vite, and Lucide icons. It synchronizes terminal execution sessions, live syscall streams, multi-device fleet telemetry, policy comparisons, and cryptographic evidence ledgers.

### Starting the Local Development Stack

```bash
# Terminal 1: FastAPI Control Plane
.venv/bin/python -m uvicorn api.main:app --host 127.0.0.1 --port 8000 --reload

# Terminal 2: React + Vite Frontend
cd frontend && npm run dev
```

Open [http://localhost:5175](http://localhost:5175) (or the displayed Vite port) in your browser.

### Key Console Features

1. **Interactive Architecture Pipeline:** Real-time animated 5-step lifecycle flow (*Dynamic Observer → Policy Minimizer → Safety Gate → Kernel Seccomp → Fleet Supervisor*).
2. **Active Node Context Switcher:** Dynamic topbar dropdown allowing operators to toggle inspection between the central server gateway and any remote Linux PC. When a device is selected, the entire dashboard scopes to that specific computer's live telemetry, kernel status, and security events.
3. **Collapsible Navigation Panel:** Hideable side navigation with smooth slide transitions and 1-click topbar toggle for distraction-free operations.
4. **Hero Quick Launch Cards:** Instant shortcuts to Fleet Pairing, Terminal Sandbox, Counterfactual Ablation, and Evidence Ledgers.
5. **Terminal / Execute Console:** Interactive browser terminal connected to the execution supervisor with preset vectors, policy preview, and support for dispatching commands either locally or directly to remote fleet endpoints under kernel confinement.
6. **Runtime Monitor:** Live and recorded system-call event stream with category tags (`File I/O`, `Memory`, `Process`, `Network`, `Privileged`) and violation alerts.
7. **Policy Explorer & Comparator:** Diff baseline vs counterfactual policies, inspect tier classifications (`experimentally_necessary` vs `removable_for_tested_tasks`), and review withheld critical syscalls.
8. **Evidence Ledgers & Safety Gate:** Inspect append-only JSONL trial records, run independent ledger audits, and inspect safety gate approvals.

## 5. Multi-Device Fleet Security & Remote Linux Agent

PoViShield extends into a distributed Linux fleet security platform. Users can pair remote Linux computers via single-use, cryptographically bound pairing codes, inspect kernel security capabilities, dispatch policy-monitored commands, and revoke authorizations in real time.

```
                    Central Control Plane (FastAPI + React Console)
                           ▲                            ▲
             HTTPS (poll)  │                            │  HTTPS (poll)
                           ▼                            ▼
            Remote Endpoint 1 (Linux)    Remote Endpoint 2 (Linux)
            Outbound-only pull loop      Zero open inbound ports
```

### Security & Privacy Guarantees

- **Outbound-Only Pull Architecture:** The local Linux agent (`agent/povishield_agent.py`) connects outbound to the control server over HTTPS. It never listens on open public ports, preventing port scanning and arbitrary incoming network attacks.
- **Short-Lived, Single-Use Pairing:** Pairing codes expire after 10 minutes and can only be consumed once. Each pairing attempt is rate-limited (5/min per IP/user) to prevent brute-force exploitation.
- **Strict User Ownership Isolation:** Devices, tasks, and telemetry are isolated per authenticated user (`X-PoViShield-User` / bearer auth). One user cannot inspect or control another user's fleet.
- **Truthful Capability Probing:** The agent directly queries the Linux kernel (`/proc/self/status` for seccomp, `prctl(PR_SET_NO_NEW_PRIVS)`, cgroups v2, user namespaces). It never claims enforcement is active if unsupported by the host.
- **Fail-Closed Seccomp Confinement:** Commands executed under `enforce` mode are confined by libseccomp filters. Unauthorized syscalls result in immediate kernel `SIGSYS` termination (exit code 159 / -31).
- **Privacy by Default:** By default, command stdout and stderr are kept local or redacted unless explicit output-sharing is authorized.
- **Instant Revocation & Cleanup:** Revoking a device instantly invalidates its bearer token, terminates or rejects pending tasks, and halts telemetry reporting.

### Device Pairing & Installation Flow

#### Option A: One-Liner Web Installer
On the target Linux machine, open a terminal and run the command provided by the connection wizard:
```bash
curl -sSL https://<server-domain>/install.sh | bash -s -- --server https://<server-domain> --code <PAIRING-CODE>
```

#### Option B: Local CLI Commands
If the repository or CLI is already present on the target host:
```bash
# 1. Probe local kernel security capabilities truthfully:
./povishield agent probe

# 2. Pair with the central control plane:
./povishield agent pair --server https://<server-domain> --code <PAIRING-CODE>

# 3. Start the outbound heartbeat supervisor loop:
./povishield agent start

# Or run a single heartbeat iteration (useful for testing or cron jobs):
./povishield agent start --once
```

## 6. Production Deployment Guide

### A. Static Frontend Hosting
Compile the optimized production bundle:
```bash
cd frontend && npm run build
```
Deploy the generated `frontend/dist/` directory to any static host (Vercel, Cloudflare Pages, Netlify, AWS S3 / CloudFront, or Nginx).

### B. FastAPI Control Plane (Backend)
Run the control plane behind an HTTPS reverse proxy (Nginx, Caddy, or Cloudflare) with standard TLS certificates:
```bash
uvicorn api.main:app --host 0.0.0.0 --port 8000 --workers 4
```

Environment variables:
- `POVISHIELD_DATABASE_URL`: Path to persistent SQLite database (default: `results/povishield.db`) or PostgreSQL connection string.
- `POVISHIELD_ALLOWED_ORIGINS`: Comma-separated list of allowed frontend origins (e.g. `https://povishield.yourdomain.com`).
- `POVISHIELD_MONITOR_ALLOW`: Colon-separated list of additional safe binary paths permitted for live tracer sessions.

### C. Systemd Service for Linux Agent
To run the PoViShield agent as a persistent background daemon on a managed Linux host:

Create `/etc/systemd/system/povishield-agent.service`:
```ini
[Unit]
Description=PoViShield Linux Endpoint Security Agent
After=network.target

[Service]
Type=simple
User=youruser
WorkingDirectory=/path/to/povishield
ExecStart=/path/to/povishield/povishield agent start
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Enable and start the service:
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now povishield-agent.service
```

### D. Container & Cloud Sandboxing Caveat
If deploying the agent or runner inside Docker or Kubernetes containers, ensure the container runtime allows seccomp filter installation (`--security-opt seccomp=unconfined` or custom profiles permitting `PR_SET_NO_NEW_PRIVS` and `SCMP_ACT_KILL_PROCESS`). Standard unprivileged cloud containers with default Docker seccomp profiles may block nested seccomp initialization.

## 7. Security Architecture & Assurance

| Layer | Mechanism | Security Guarantee | Source |
|---|---|---|---|
| **Supervisor** | `analysis/runner.py`, `./povishield` | Safe argument parsing, pre-execution evaluation, session timeline logging | [`analysis/runner.py`](analysis/runner.py) |
| **Learner** | `ptrace` (PTRACE_SYSCALL) | Traverses fork/clone/exec, logs events to JSONL, atomic profile generation | [`src/tracer/learn.c`](src/tracer/learn.c) |
| **Ablation** | Leave-one-out minimization | Empirically proves permissions unnecessary under `SCMP_ACT_KILL_PROCESS` | [`analysis/ablate.py`](analysis/ablate.py) |
| **Evidence Ledger** | Append-only JSONL | SHA-256 trial hashes, reproduce commands, fail-closed verification | [`analysis/ledger.py`](analysis/ledger.py) |
| **Safety Gate** | Pre-enforcement verification | Regression testing, adversarial containment, fail-closed approval gate | [`analysis/verify.py`](analysis/verify.py) |
| **Enforcement** | libseccomp BPF filter | Strict allowlist, `PR_SET_NO_NEW_PRIVS`, kernel SIGSYS termination on violation | [`src/policy/seccomp_gen.c`](src/policy/seccomp_gen.c) |
| **Container Sandbox** | Namespaces + cgroup v2 | PID/mount/UTS/IPC/net isolation, `pivot_root`, resource caps (needs root) | [`src/runtime/sandbox.c`](src/runtime/sandbox.c) |
| **Fleet Auth** | Single-use token + SHA-256 | Single-use 10m TTL pairing code, rate limiting, instant token revocation | [`api/auth.py`](api/auth.py), [`api/database.py`](api/database.py) |
| **Control Plane API** | FastAPI + Uvicorn | DNS rebinding protection, CORS loopback validation, input allowlisting | [`api/main.py`](api/main.py) |

## 8. Threat Model & Limitations

- **Empirical Coverage:** A profile covers only observed or counterfactually verified behavior. It cannot predict untested execution paths.
- **Syscall Arguments:** Standard Seccomp filters validate syscall numbers and scalar arguments; pointer targets in user memory are subject to TOCTOU unless inspected by specialized tracers.
- **Host Security:** Seccomp restricts system calls from the target process; it does not replace kernel isolation or mitigate unpatched kernel vulnerabilities.
- **Learn Mode Safety:** Dynamic tracing via ptrace should only be conducted on trusted binaries during policy generation.
